Who is StaticPilot for?+

Developers and small teams building custom PHP websites for businesses, portfolios, and product showcases. It gives clients a focused dashboard without taking control of your frontend.

Do I need a database?+

No. StaticPilot stores content in JSON files. You’ll need a PHP-capable server and writable, protected storage. See the repository for installation and deployment guidance.

Can I use my existing website design?+

Yes. Keep your existing layout, styles, and scripts. Include the PHP content adapter and replace hardcoded text with the supplied variables and arrays.

Where do my images live?+

In your website’s assets folder or external hosting. StaticPilot focuses on editable content and does not include a media library or image uploads.

Can the CMS run on GitHub Pages?+

This project page can. The CMS itself requires PHP hosting, so it cannot run on GitHub Pages. The two are separate: this page introduces the project; your PHP server runs the dashboard.
